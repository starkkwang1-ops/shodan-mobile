API Key

安装到主屏幕

在 iPhone Safari：分享 →「添加到主屏幕」。深色主题、大按钮，适合单手操作。

我的公网 IP

对应 CLI：shodan myip

主机查询

对应 CLI：shodan host <ip>

提示：搜索与部分过滤器会消耗 query credits。分页也会再次计费。
